
# StudentHub Portal

## Project Overview
StudentHub is a full-stack web application for student
management, event management, and registrations.

## Technologies Used
- HTML5
- CSS3 and Bootstrap (where used)
- JavaScript and AJAX
- PHP
- MySQL
- XAMPP
- Git and GitHub

## Features
- User authentication and session management
- Role-based access control
- Student management
- Event management and poster uploads
- Student registrations
- Admin dashboard and statistics
- Form validation and AJAX operations
- Audit logging (where implemented)

## Installation
1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the project into the XAMPP htdocs directory.
4. Import database.sql using phpMyAdmin.
5. Update db.php with the local database settings.
6. Open the application in a browser.

## Local URL
http://localhost/xampp/practical15/

## Testing
Follow the test cases documented in docs/test-report.md.

## Security
Passwords must be hashed, database queries must use
prepared statements, and protected pages must verify
authentication and authorization.
